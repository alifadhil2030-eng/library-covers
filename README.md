# مكتبة أغلفة الكتب — CDN

هذا المستودع يحتوي على أغلفة الكتب بصيغة **WebP** مُحسّنة، ويُقدَّم عبر **jsDelivr** مجاناً.

## صيغة الرابط
```
https://cdn.jsdelivr.net/gh/alifadhil2030-eng/library-covers@v1/covers/sh_001.webp
```

## إضافة آلاف الأغلفة لاحقاً
1. حوّل الصور إلى WebP:
   ```powershell
   python tools/optimize_covers.py "C:\cover-originals" "C:\cover-webp"
   ```
2. انسخ ملفات `.webp` إلى مجلد `covers/` في هذا المستودع.
3. أنشئ خريطة `id,filename` وحدّث `covers.js` في موقع المكتبة.
4. انشر tag جديداً (`v2`، `v3`، ...) وعدّل `COVER_BASE` في `index.html`، أو احتفظ بـ `@v1` واستخدم أسماء ملفات جديدة دائماً.

> ملاحظة: jsDelivr يخزّن ملفات الإصدار المؤرشف في كاش طويل. إذا استبدلت ملفاً باسمه نفسه دون تغيير الإصدار، قد يظهر القديم لدى الزوار — استخدم اسماً جديداً أو إصداراً جديداً.
